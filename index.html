A BETTER STARTING POINT FOR TYPE

A free typography scale generator for consistent design systems

Type Scale Studio helps designers and developers create a modular typography scale from a base font size and scale ratio. Preview heading and body sizes in context, tune the rhythm of your type system, and export reusable design tokens for real projects.

Build responsive typography and export design tokens

Use the fluid CSS export to generate responsive font sizes with clamp(). Choose standard CSS variables, JSON tokens, or a Tailwind theme configuration to bring your type scale into a website, app, or design system.

What is a modular type scale?

A modular type scale is a set of font sizes created with a consistent mathematical ratio. It gives headings, subheadings, and body text a predictable visual relationship, helping interfaces feel more structured and readable.

Is Type Scale Studio free?

Yes. The typography scale generator runs in your browser and is free to use. Your settings and generated tokens stay in the page; no account is required.
