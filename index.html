Create a modular typography scale for your design system

Type Scale Studio is a free typography scale generator for UI designers, graphic designers, and front-end developers. Set a base font size, choose a mathematical scale ratio, and generate a coordinated set of text sizes for body copy, labels, headings, and display type. Preview the hierarchy immediately, then copy the tokens into your project.

How to use the typography scale generator

  1. Choose a base size. Start with a body text size such as 16px. This is the anchor for the rest of the scale.
  2. Set a scale ratio. Select a subtle or dramatic relationship between adjacent type sizes. A larger ratio creates more contrast between headings and body text.
  3. Choose the number of steps. Generate smaller and larger sizes around the base to cover captions, body text, headings, and display styles.
  4. Preview the type hierarchy. Review the specimen rows and adjust the settings until the scale suits your interface or brand.
  5. Export your design tokens. Copy CSS variables, fluid CSS using clamp(), JSON, or a Tailwind font-size theme.

What is a modular type scale?

A modular type scale is a set of font sizes built by repeatedly multiplying or dividing a base size by the same ratio. This creates a consistent mathematical relationship between text styles. For example, with a 16px base and a 1.25 ratio, the next larger sizes are 20px, 25px, and 31.25px. Smaller steps are calculated by dividing the base by the ratio.

Designers use modular scales to create a clear typographic hierarchy without choosing every size independently. The scale is a starting point, not a rule: adjust individual styles when readability, content density, or a specific layout calls for it.

Which typography scale ratio should you choose?

  • 1.067 — minor second: very subtle steps for dense interfaces and compact dashboards.
  • 1.125 — major second: restrained contrast for applications with many text levels.
  • 1.2 — minor third: balanced hierarchy for websites and product interfaces.
  • 1.25 — major third: clear heading contrast and a useful general-purpose starting point.
  • 1.333 — perfect fourth: more expressive hierarchy for editorial layouts and landing pages.
  • 1.5 — perfect fifth: strong contrast for display-led designs.
  • 1.618 — golden ratio: dramatic jumps for highly expressive typography.

There is no universally correct ratio. Start with 1.2 or 1.25, then inspect real headings and paragraphs at desktop and mobile widths.

Generate responsive typography with CSS clamp()

A responsive typography generator should help text adapt between viewport sizes rather than simply shrinking every heading. Type Scale Studio's Fluid CSS export creates a clamp() expression for each token, with a minimum and maximum viewport width that you configure. Each generated size interpolates from 90% to 110% of its static token value across that viewport range.

CSS clamp() combines a minimum, a preferred fluid value, and a maximum. It lets text scale smoothly while retaining readable bounds. Always test the resulting sizes with your actual content, font family, line height, and layout.

Export CSS typography tokens for your project

  • CSS variables: reusable custom properties in a :root block.
  • Fluid CSS: responsive custom properties using clamp().
  • JSON: structured token values for design systems and build tools.
  • Tailwind: a font-size theme extension to adapt for your Tailwind configuration.

Use the token prefix field to name variables for your project. For example, a prefix of type creates tokens such as --type-base and --type-lg-2.

Frequently asked questions

Is this typography scale generator free?

Yes. Type Scale Studio is free to use in your browser. No account or payment is required.

What is the best base font size for a website?

16px is a common starting point for body text, but the right base depends on your chosen typeface, audience, layout, and accessibility needs. Preview your actual content before deciding.

What is the difference between a modular and responsive type scale?

A modular scale defines the mathematical relationship between font sizes. A responsive scale also adapts those sizes to the available viewport, for example with CSS clamp().

Can I export CSS variables and Tailwind tokens?

Yes. Choose CSS, Fluid CSS, JSON, or Tailwind in the export panel and copy the generated code.

Does this tool upload my settings?

The scale is generated in your browser. The tool does not require an account or a project upload to calculate and export the tokens.
