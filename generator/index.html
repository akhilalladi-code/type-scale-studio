Build a modular type scale for your design system
Type Scale Studio is a free typography scale generator for designers and developers. Choose a base font size, set a mathematical ratio and create a coordinated hierarchy for captions, body copy, headings and display text. Preview your choices and export reusable tokens without creating an account.
What is a modular typography scale?
A modular type scale is a sequence of font sizes created by repeatedly multiplying a base size by a consistent ratio. For example, a 16px base with a 1.25 ratio produces larger steps of 20px, 25px and 31.25px. This gives text styles a predictable relationship while leaving room for optical adjustments.
Which type scale ratio should you use?
Try 1.2 (Minor Third) for a restrained interface, 1.25 (Major Third) for a versatile website hierarchy, or 1.333 (Perfect Fourth) for more expressive editorial layouts. Dense dashboards often benefit from smaller ratios; display-led pages can use stronger contrast. Always test the result with real content.
Create responsive typography with CSS clamp()
Use the Fluid CSS export to create responsive font-size tokens with clamp(). Each value has a minimum, a fluid preferred size and a maximum, helping typography scale smoothly between viewport widths. Preview the system in the interactive typography canvas before shipping it.
Export CSS, JSON and Tailwind typography tokens
Export standard CSS custom properties, fluid CSS, JSON tokens or a Tailwind font-size theme. Continue in the token manager to review and adjust values, or save a configuration in the preset library.
Frequently asked questions
Is this typography scale generator free?
Yes. It runs in your browser and does not require an account.
What is a good base font size?
16px is a common starting point for body copy, but the right size depends on the typeface, audience and reading context.
What is the difference between modular and responsive typography?
A modular scale defines relationships between sizes. Responsive typography adapts those sizes to the viewport, for example with CSS clamp().
